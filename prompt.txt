# PRD - Car Simulator Android Realistis (Open World Kota Modern)
> Free roam 3D kota modern dengan interior/kabin detail, offline, Unity untuk Android.

## 1. Ringkasan
Masalah: game car simulator Android yang ada kebanyakan interior seadanya, handling arcade, map generik.
Solusi: open world kota modern fokus free roam + interior/kabin (setir, dashboard, spion) + handling realistis ringan untuk HP mid-range.
Target: pemain kasual Indonesia 13-30th, HP Android RAM 4-6GB, suka keliling bebas tanpa misi berat.
Menang vs kompetitor: interior detail + performa ringan + map kota modern padat (bukan map kosong).

## 2. User & Persona
- Utama: Pemain kasual (free roam, grafik bagus, kontrol gampang, offline, hemat baterai).
- Secondary: Enthusiast mobil (mau ganti kamera interior/luar, coba handling beda per mobil).
- Device: Android 9+, landscape, touch + gyro opsional, 60fps target di mid-range, 30fps minimum di low.

## 3. Scope MVP
### In-scope (F-01..F-05)
- F-01: Driving + fisika arcade-realistis (akselerasi, rem, steering, tabrakan sederhana)
- F-02: Interior/kabin detail (dashboard, setir animasi, spion, kamera dalam/luar)
- F-03: Map kota modern kecil padat (tol, gedung, parkiran mall, SPBU)
- F-04: 2-3 mobil berbeda handling + ganti warna
- F-05: Kontrol mobile + HUD + save lokal + setting grafik
### Out-of-scope (eksplisit)
- Multiplayer online, misi/karier, traffic AI padat + lampu merah penuh, cuaca dinamis penuh (hujan/salju), BBM/servis/modif bengkel, interior multi-merek lisensi.

## 4. User Flow Utama
1. Buka game -> Menu utama (Start, Pilih Mobil, Setting) <3 detik load.
2. Pilih mobil -> Spawn di parkiran mall -> tutorial kontrol 10 detik (gas/rem/setir/kamera).
3. Free roam: nyetir keliling, ganti kamera (dalam/luar), tabrakan -> damage visual ringan, pause -> resume/exit, progres (mobil terakhir + posisi) tersimpan otomatis.

## 5. Spec Fitur (per fitur)
### F-01 Driving + Fisika
- Deskripsi: WheelCollider-based, beda handling sedan vs SUV, rem tangan, kamera follow stabil.
- Acceptance: Given gas penuh di jalan lurus When 5 detik Then capai 80-120km/jam stabil no jitter; Given rem mendadak 60km/jam When rem Then berhenti <25m; Given tabrak tembok 40km/jam When tabrak Then mobil mental + damage visual, tidak tembus.
- UI state: HUD speed, RPM bar, tombol gas/rem/setir kiri-kanan.
- Butuh: Unity WheelCollider, Rigidbody tuning, Input Touch.
- Edge: FPS drop saat tabrakan beruntun, HP panas -> batasi particle.

### F-02 Interior/Kabin
- Deskripsi: dashboard + setir putar ikut steering, spion tengah/kanan-kiri render sederhana, kaca transparan.
- Acceptance: Given kamera dalam When belok kiri Then setir putar kiri sinkron; Given siang When di kabin Then dashboard terbaca no overexposure; Given ganti kamera When tekan tombol Then <0.3 detik switch tanpa freeze.
- UI state: tombol kamera, hide UI mode foto.
- Butuh: model interior low-poly detail, mirror pakai RenderTexture resolusi rendah.
- Edge: spion matikan otomatis di setting Low.

### F-03 Map Kota Modern Kecil
- Deskripsi: 1x1km padat: jalan tol pendek, gedung 10-15, parkiran mall spawn, SPBU pajangan, rambu + lampu jalan statis.
- Acceptance: Given keliling map When 3 menit Then tidak keluar batas (invisible wall + pembatas visual); Given low setting When render Then >30fps di Snapdragon 665 setara; Given malam When lampu jalan Then jalan terlihat tanpa lightmap berat.
- UI state: minimap sederhana (opsional MVP, boleh Personality).
- Butuh: modular road pieces, occlusion culling, LOD gedung.
- Edge: hindari lubang collider di sambungan jalan.

### F-04 Mobil + Varian
- Deskripsi: 2 mobil MVP (sedan + SUV), beda akselerasi/handling/suara, ganti warna 5 pilihan tersimpan.
- Acceptance: Given pilih SUV When nyetir Then terasa lebih berat vs sedan; Given ganti warna When pilih Then tersimpan setelah restart.
- Butuh: 2 prefab mobil + audio engine loop pitch by speed.
- Edge: suara tidak pecah di speaker kecil.

### F-05 Kontrol + Save + Setting
- Deskripsi: tombol touch (gas/rem/steer), gyro opsional, HUD speed, pause, setting grafik Low/Med/High + kualitas bayangan + spion on/off.
- Acceptance: Given HP mid When default Med Then 45-60fps; Given exit When balik Then posisi/mobil tersimpan; Given Low When aktif Then spion off + shadow off otomatis.
- Butuh: PlayerPrefs save, URP asset per tier.
- Edge: layout tombol tidak nutup spion di layar 18:9.

## 6. Skema Data (sederhana, lokal dulu)
- PlayerProfile: selectedCarId, colorId, lastPosition(x,y,z), graphicTier, gyroOn [PlayerPrefs/Json, offline]
- CarDef (ScriptableObject): id, name, topSpeed, accel, handling, prefabRef
- MapSection: id, bounds, LODGroup ref [tidak perlu DB real di MVP]
- [Asumsi] No backend. Leaderboard/multiplayer ditunda.

## 7. API Contract
MVP offline -> tidak ada API. disiapkan untuk nanti:
- GET /catalog/cars - list mobil (untuk update OTA katalog, post-MVP)
- POST /telemetry/session - kirim durasi main + crash count (post-MVP, opt-in)

## 8. Non-fungsional
- Performa: APK <300MB, RAM <1GB saat main, load menu <3 detik, target 60fps Med di SD720G.
- Keamanan: no secret di client, validasi save file sederhana anti cheat santai.
- Kompat: Android 9+, ARMv7+ARM64, landscape, teks Indonesia, ikon 512.
- Audio: engine + tabrakan + tombol, mute switch.
